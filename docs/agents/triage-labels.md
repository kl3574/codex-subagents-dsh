# Triage labels

| Role | GitHub label | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | Maintainer needs to evaluate the request |
| Needs information | `needs-info` | Waiting for missing information |
| Ready for an agent | `ready-for-agent` | Scope and acceptance criteria are settled |
| Ready for a human | `ready-for-human` | Requires a human action |
| Will not implement | `wontfix` | Will not be actioned |

Reuse existing labels and preserve unrelated labels. Create only missing labels
from this table.
